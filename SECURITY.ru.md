# Политика безопасности

## Как сообщить об уязвимости

Сообщайте об уязвимости **приватно**, одним из двух способов:

- через GitHub: **Security → Report a vulnerability** в нужном репозитории (приватная заметка, которую видит только maintainer);
- по почте: **support@vazie.app**, в теме укажите «Security».

**Не создавайте публичные issue, обсуждения и pull request по проблемам безопасности** и не публикуйте подробности до
выхода исправления.

Никогда не присылайте настоящие данные для доступа: базу паролей, файл ключа, ссылку `vless://` или ссылку на
подписку. Опишите проблему на выдуманных данных (`example.com`, адреса для документации вроде `192.0.2.1`).

Что поможет разобраться:

- версия приложения и версия операционной системы;
- что может сделать атакующий и что ему для этого нужно (физический доступ, другое приложение на устройстве, положение в сети);
- шаги воспроизведения или proof of concept, который не затрагивает настоящие аккаунты и серверы.

## Что будет дальше

- Ответ о получении в течение 7 дней.
- Оценка и, для подтверждённой проблемы, план исправления.
- Исправление в релизе и упоминание в его заметках, если вы не предпочтёте остаться анонимным.

Программы вознаграждения за найденные ошибки нет.

## Область действия

Все репозитории этой организации входят в область действия. Модель угроз каждого проекта описана в его папке `docs`;
известные ограничения платформ перечислены там же и уязвимостями не считаются.
