# Support

- **Using an app?** Each project's README and `docs` folder have the install guide and troubleshooting.
- **Found a bug or want a feature?** Open an issue in the project's repository.
- **Security problem?** Do not open an issue: see [SECURITY.md](SECURITY.md).
- **Anything else:** [support@vazie.app](mailto:support@vazie.app) or Telegram [@vazieapp](https://t.me/vazieapp).

Never send real passwords, databases, keys or subscription links, even to support.
