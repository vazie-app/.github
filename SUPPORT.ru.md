# Поддержка

- **Пользуетесь приложением?** В README и папке `docs` каждого проекта есть инструкция по установке и решение проблем.
- **Нашли ошибку или хотите функцию?** Создайте issue в репозитории проекта.
- **Проблема безопасности?** Не создавайте issue: см. [SECURITY.ru.md](SECURITY.ru.md).
- **Всё остальное:** [support@vazie.app](mailto:support@vazie.app) или Telegram [@vazieapp](https://t.me/vazieapp).

Никогда не присылайте настоящие пароли, базы, ключи и ссылки на подписки, даже в поддержку.
