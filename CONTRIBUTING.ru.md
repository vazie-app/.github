# Как участвовать

Спасибо, что помогаете Vazie. В каждом репозитории есть свой `CONTRIBUTING.md` с шагами сборки и правилами проекта;
здесь — то, что общее для всех.

## Основные правила

1. **Никогда не коммитьте и не публикуйте настоящие секреты**: пароли, базы, ключи, конфигурации, ссылки на подписки,
   токены и личные данные — ни в коде, ни в тестах, логах, скриншотах или issue.
2. **Никакой телеметрии, аналитики и нового сетевого доступа** без предварительного обсуждения.
3. **Обосновывайте новые зависимости** в описании pull request. Предпочитайте стандартную библиотеку платформы.
4. **Делайте небольшие изменения.** Один pull request — одно изменение; исправлению ошибки не нужен рефакторинг рядом.

## Прежде чем начать

- Нашли ошибку? Поищите среди issue, затем создайте новое по форме нужного репозитория.
- Хотите функцию? Создайте issue и сначала опишите проблему. Короткое обсуждение избавит от отклонённого pull request.
- Проблема безопасности? Не создавайте issue: см. [SECURITY.ru.md](SECURITY.ru.md).

## Pull request

- Ветвитесь от `main`.
- Используйте [Conventional Commits](https://www.conventionalcommits.org/ru): `feat(core): …`, `fix(android): …`, `docs: …`.
- Перед отправкой запустите проверки проекта; команда указана в руководстве конкретного репозитория.
- Объясните, что изменилось и как вы это проверили. Для всего видимого пригодятся скриншоты.

Участвуя, вы соглашаетесь, что ваша работа распространяется под лицензией того репозитория, в который вы вносите
изменения. Соблюдайте [Кодекс поведения](CODE_OF_CONDUCT.ru.md).
